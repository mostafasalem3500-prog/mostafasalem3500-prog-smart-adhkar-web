# Smart Adhkar Web | سمارت أذكار ويب

نسخة ويب عربية من مشروع **Smart Adhkar**، تعمل على الجوال والكمبيوتر وقابلة للإضافة إلى الشاشة الرئيسية كتطبيق PWA.

## المزايا

- مكتبة أذكار موثقة ومصنفة.
- أذكار الصباح والمساء وما بعد الصلاة والسفر والمطر والنوم وغيرها.
- عرض المصدر الشرعي والمرجع الرسمي لكل ذكر.
- البحث والتصفية والمفضلة.
- جلسات ورد صباح/مساء/بعد الصلاة مع حفظ التقدم محليًا.
- مسبحة إلكترونية بأهداف جاهزة ومخصصة.
- الاستماع للنص العربي عبر Speech Synthesis عندما يدعمه المتصفح.
- وضع فاتح وداكن.
- PWA + Service Worker.
- Privacy-first: بيانات الاستخدام الشخصية تبقى في المتصفح.

## التشغيل محليًا

```bash
npm start
```

ثم افتح `http://localhost:3000`.

## Railway

المشروع جاهز للنشر على Railway ويحتوي `railway.toml` ومسار فحص صحة:

`/health`

## المصادر الشرعية

تعتمد المكتبة على مصادر موثوقة، من بينها **حصن المسلم من أذكار الكتاب والسنة**، الموقع الرسمي للشيخ ابن باز، ومجمع الملك فهد لطباعة المصحف الشريف للنصوص القرآنية.
